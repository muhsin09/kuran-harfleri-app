# Harfleri Öğren Sayfası Wireframe

```
+-----------------------------------------------------+
|                                                     |
|  [Geri]              HARFLERİ ÖĞREN                 |
|                                                     |
+-----------------------------------------------------+
|                                                     |
|                                                     |
|                                                     |
|                +-------------------+                |
|                |                   |                |
|                |                   |                |
|                |        ا          |                |
|                |      (ELİF)       |                |
|                |                   |                |
|                |                   |                |
|                +-------------------+                |
|                                                     |
|                                                     |
|                                                     |
|  [Önceki]                              [Sonraki]    |
|                                                     |
|                                                     |
|                                                     |
|  +-------------------------------------------+      |
|  |                                           |      |
|  |           NESNE GÖRSELİ                   |      |
|  |        (Harfle başlayan nesne)            |      |
|  |                                           |      |
|  +-------------------------------------------+      |
|                                                     |
|                                                     |
|  [Ses Simgesi]         [Tekrar Et]                  |
|                                                     |
+-----------------------------------------------------+
```

## Açıklamalar:

1. **Başlık:** "HARFLERİ ÖĞREN" - Büyük, renkli ve çocuk dostu bir yazı tipi ile
2. **Geri Butonu:** Ana sayfaya dönüş için
3. **Harf Gösterimi:** 
   - Ortada büyük boyutta Arap alfabesi harfi (ا، ب، ت...)
   - Harfin altında Türkçe okunuşu (ELİF, BE, TE...)
4. **Navigasyon Butonları:** 
   - "Önceki" ve "Sonraki" butonları ile harfler arası geçiş
   - Büyük ve renkli ok simgeleri ile
5. **Nesne Görseli:** 
   - Harfle başlayan bir nesnenin görseli (örn. ا için أرنب/tavşan görseli)
   - Büyük ve net görsel
6. **Ses Kontrolleri:**
   - "Ses Simgesi": Tıklandığında harfin adını seslendirir
   - "Tekrar Et": Tıklandığında sesi tekrar çalar
7. **Etkileşim:**
   - Harfe tıklandığında harfin sesi otomatik çalar
   - Nesne görseline tıklandığında nesnenin adı seslendirilir
8. **Mobil Uyumluluk:** Dikey düzen, farklı ekran boyutlarına uyumlu
