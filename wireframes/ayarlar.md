# Ayarlar Sayfası Wireframe

```
+-----------------------------------------------------+
|                                                     |
|  [Geri]                 AYARLAR                     |
|                                                     |
+-----------------------------------------------------+
|                                                     |
|                                                     |
|  +-------------------------------------------+      |
|  |                                           |      |
|  |             SES SEVİYESİ                  |      |
|  |                                           |      |
|  |  [Sessiz] ---|--------O-------- [Yüksek]  |      |
|  |                                           |      |
|  +-------------------------------------------+      |
|                                                     |
|                                                     |
|  +-------------------------------------------+      |
|  |                                           |      |
|  |             HARF SETİ SEÇİMİ              |      |
|  |                                           |      |
|  |  [ ] İlk 5 harf (ا ب ت ث ج)              |      |
|  |  [ ] İlk 10 harf                          |      |
|  |  [ ] Tüm harfler                          |      |
|  |                                           |      |
|  +-------------------------------------------+      |
|                                                     |
|                                                     |
|  +-------------------------------------------+      |
|  |                                           |      |
|  |             [KAYDET]                      |      |
|  |                                           |      |
|  +-------------------------------------------+      |
|                                                     |
|                                                     |
|  [Ebeveyn Bilgisi]                                  |
|                                                     |
+-----------------------------------------------------+
```

## Açıklamalar:

1. **Başlık:** "AYARLAR" - Büyük, renkli ve çocuk dostu bir yazı tipi ile
2. **Geri Butonu:** Ana sayfaya dönüş için
3. **Ses Seviyesi Ayarı:** 
   - Kaydırmalı ses seviyesi kontrolü
   - Sessiz ve yüksek ses simgeleri ile
4. **Harf Seti Seçimi:** 
   - Farklı harf seti seçenekleri (ilk 5, ilk 10, tüm harfler)
   - Büyük ve kolay seçilebilir onay kutuları
5. **Kaydet Butonu:**
   - Büyük ve belirgin
   - Tıklandığında ayarları kaydeder ve ana sayfaya döner
6. **Ebeveyn Bilgisi:**
   - Ebeveynlere yönelik kısa bilgi notu
   - "Bu ayarlar çocuğunuzun öğrenme seviyesine göre düzenlenebilir"
7. **Mobil Uyumluluk:** Dikey düzen, farklı ekran boyutlarına uyumlu
8. **Erişilebilirlik:** Büyük dokunma alanları, net etiketler
